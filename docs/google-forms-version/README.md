# Google Forms version (current live system)

The first version of the invigilation system, running in Google Apps Script
until TWELVE replaces it.

- `Test_Room_Builder_Script.txt` — builds the Form, answers Sheet, room QR codes, desk QR, alerts and the 8:10 missing-room check
- `Sample_Data_Addon.txt` — `fillSampleData` / `deleteSampleData` test helpers
- `Sample_Data_Prompt.txt` — browser prompt for submitting sample reports (did not work; use the add-on instead)
